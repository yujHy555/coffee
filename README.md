# ☕ Cuppa Quest: The Magical Roastery

An interactive, AAA-inspired 2D side-scrolling action platformer and interactive product discovery experience built with HTML5 Canvas, procedural Web Audio synthesis, and Vite.

## ✨ Features

- **Multi-Biome Magical Coffee World**:
  - **Zone 1 — Starry Espresso Hills**: Twinkling night skies, glowing golden coffee plants, distant espresso machines and burr grinders, giant mossy coffee bean boulders, crystalline sugar cube arches, and swirling milk rapids.
  - **Zone 2 — Sunset Biscotti Grove**: Latte-art sunset clouds, glowing coffee cherry trees, crumbling almond biscotti islands, chocolate-dipped sandwich cookies, and gingerbread royal-icing cliffs over a boiling crema lake.
- **Fully Animated Coffee Cup Hero**:
  - Sloshing espresso inside the cup rim, rising steam particles, expressive eyes, red boots, squash-and-stretch physics, **Silver Barista Spoon melee**, **Espresso Shot projectiles**, and **Frothy Dash**.
- **Interactive Product Discovery & Power-Ups**:
  - Discover 4 signature coffee products hidden throughout the world (or preview them anytime via the **Product Vault** button in the top HUD).
  - Each discovered product opens a rich **Product Showcase Card** (with origin, roast profile, tasting notes, and shop link) paired with a permanent **In-Game Power-Up**!

## 🎮 Controls

- **Move**: `A` / `D` or `Left` / `Right` Arrow Keys
- **Jump / Double Jump**: `Space`, `W`, or `Up` Arrow
- **Silver Spoon Melee**: `Z` or `J`
- **Espresso Shot Projectile**: `X` or `K`
- **Frothy Dash**: `Shift`, `C`, or `L`

## 🚀 Local Development & Deployment

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle (outputs to dist/)
npm run build
```

### Deploying to GitHub & Vercel
1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo>.git
   git push -u origin main
   ```
2. Import the GitHub repository in [Vercel](https://vercel.com/new) — `vercel.json` is pre-configured to build and deploy automatically.
